# Safe-Route
SafeRoute is an AI-powered women safety platform with live tracking, safe route suggestions, SOS alerts, and danger-zone detection. It helps users travel safer by sending real-time emergency alerts and location updates to trusted contacts during emergencies.
Project Overview: 
SafeRoute SG is a single-page web application that transforms neighborhood-level safety micro-data into actionable insights for people relocating to Bangalore—especially students, international newcomers, and young professionals evaluating where to live, commute, and socialize. Instead of relying on anecdotal advice or generic city guides, SafeRoute SG surfaces quantified safety scores, accessibility ratings, and granular street-level metrics (lighting, crowd density, security presence) on an interactive map. Users can search, filter, and drill into any location to understand risk profiles before making housing or routing decisions.The product is designed as both a consumer-facing navigator and a B2B data layer that student housing platforms, PG aggregators, and co-living operators can embed to differentiate listings with trust-building safety intelligence.
